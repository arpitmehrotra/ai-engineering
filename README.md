# AI Engineering

Hands-on implementations of AI engineering concepts, built with TypeScript and local models.

## Contents

| Folder | Description |
| --- | --- |
| `agent/` | A tool-using agent built without a framework, running on a local model via Ollama |
| `notes/` | Notes accompanying each implementation |

## Requirements

- Node.js 20+
- [Ollama](https://ollama.com) with `qwen3:8b` pulled

## Getting started

```bash
cd agent
npm install
cp .env.example .env
npm start
```

All data in this repository is fictional.
